現在のトップページにはキービジュアルと簡単なプロフィールカードしか存在しておらず、他ページに遷移しなければ情報を得られない。キービジュアルの下にセクションを追加し、いくつかピックアップした作品を横に流したり、aboutページの内容の一部をトップページに統合したりしたい。



# 注意
1. まず実装計画を `docs/` にMDファイルとして作成し、ユーザーに検討させる事項がある場合はユーザーに判断を仰ぐこと。
2. トップページと関連ファイルに破壊的な変更を加える可能性があるので、新規にfutureブランチを作ってそこで作業すること。
3. 作品を横に流すやつの実装に関しては [このサイト](https://ajalaca.com/) を参考にすること。
4. 作品を横に流すやつに使用する画像にはサムネイル用の画像を使用したほうが、縦長と横長のイラストが混在している元データを使うより勝手が良さそう。
5. スタイルに関しては `global.css` と `about/page.module.css` のものを利用すること。
